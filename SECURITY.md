# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последней версии `0.1.x`.

## Сообщение об уязвимости

Не публикуйте токены, персональные данные, приватные видео и полные журналы с
локальными путями в открытом issue. Используйте **Private vulnerability
reporting** на вкладке **Security** репозитория. Если эта функция недоступна,
создайте issue без чувствительных деталей и попросите сопровождающих открыть
приватный канал связи.

В сообщении укажите версию приложения, Windows, способ воспроизведения и
ожидаемое влияние. Получение отчёта обычно подтверждается в течение семи дней.
