# История изменений

Все заметные изменения проекта документируются в этом файле. Формат основан
на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют
[Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-30

### Добавлено

- Точечное глушение ненормативной лексики с пользовательскими стоп-словами.
- Нарезка стримов с удалением пауз, донатов и чтения чата.
- Экспорт MP4 и таймлайна DaVinci Resolve XML.
- Пакетная обработка файлов и папок.
- Локальное распознавание речи через faster-whisper с CUDA и CPU fallback.
- Windows-интерфейс на pywebview и Edge WebView2.
- Самопроверка собранного приложения и автоматическая подготовка GitHub Release.
